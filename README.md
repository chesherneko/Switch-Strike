# Switch Strike

`Switch Strike`는 두 캐릭터를 교대하며 싸우는 2D 사이드뷰 액션 플랫포머입니다.<br/>
점프·대시·벽 점프로 횡스크롤 스테이지를 돌파하고, 전투 중 모은 게이지로 캐릭터를 교대해 위기를 반격 기회로 바꾸는 것이 핵심입니다.

## 게임 소개

플레이어는 대검을 쓰는 **Mooni**와 낫을 쓰는 **Reaper**를 번갈아 꺼내 쓰며 스테이지를 돌파합니다.<br/>
Mooni는 최대 HP의 30%를 회복하는 스킬을, Reaper는 공중에 떠올라 무적 상태로 버티다 하강 공격하는 스킬을 가지고 있습니다. 스킬 쿨타임은 두 캐릭터가 공유하기 때문에, 지금 회복과 회피 중 무엇이 필요한지 판단해 골라 써야 합니다.

교대하는 동안에는 두 캐릭터 모두 무적이라 교대 자체를 회피 수단으로 쓸 수 있습니다.<br/>
적을 공격하거나 대시 직후의 짧은 무적 구간으로 공격을 흘리는 **완벽 회피**에 성공하면 QTE 게이지가 찹니다. 게이지가 가득 찬 상태로 교대하면 새로 들어온 캐릭터가 강력한 **QTE 등장 공격**을 펼칩니다.<br/>
완벽 회피는 일반 타격보다 게이지가 4배 많이 차기 때문에, 위험을 감수할수록 반격 기회가 빨리 옵니다.

스테이지에는 성격이 다른 몬스터 4종(전사·궁수·창병·자폭병)이 등장하고, 끝에서는 패턴 5종을 가진 보스가 기다립니다.<br/>
보스의 특수 패턴은 잘 대응하면 오히려 보스에게 큰 피해를 줄 수 있습니다.

## 조작법

| 조작 | 설명 |
| --- | --- |
| ← / → | 좌우로 이동합니다. 공중에서 벽 쪽으로 누르면 벽에 매달립니다. |
| Space | 점프합니다. 누르는 길이로 높이가 달라지고, 2단 점프와 벽 점프가 가능합니다. |
| Left Shift | 대시합니다. 대시 직후 공격을 받으면 완벽 회피가 발동합니다. |
| X | 공격합니다. 연속으로 누르면 콤보가 이어집니다. |
| Z | 캐릭터 스킬을 사용합니다. Reaper는 체공 중 다시 누르면 하강 공격합니다. |
| 1 | 캐릭터를 교대합니다. 게이지가 가득 차 있으면 QTE 등장 공격이 발동합니다. |
